# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in StreamMatrix, please report it responsibly:

1. Do **not** open a public issue on GitHub.
2. Send an email to the maintainer or use GitHub's Private Vulnerability Reporting feature.
3. Include detailed steps to reproduce the issue and any relevant logs.

We appreciate your efforts to responsibly disclose findings and will work to address verified issues promptly.
